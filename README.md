# blockchain-cryptography

一本**零基础也能看懂**的《区块链密码学在线交互书》——不只"读"，更"边读边动手"：每个知识点都配有可在浏览器里查看、修改、运行的 **Go 示例**。全书 **7 篇、41 节、41 个可运行示例**，内容严格聚焦与区块链相关的密码学。

> 无数据库 · 无登录 · 完全免费开放 · 单 Go 二进制即可部署

---

## ✨ 核心特色

- **通俗易懂**：从生活比喻切入，逐步进入学术概念，把数学讲成人话。
- **可运行示例**：41 个知识点全部配套 Go 程序，在浏览器内直接编译运行。
- **真·沙箱执行**：前端是编辑器 + 展示层，代码由后端沙箱编译运行，输出实时返回。
- **单二进制部署**：前端静态资源、教材正文、示例代码全部 `go:embed` 打进一个二进制，对外只需暴露 **一个端口**。
- **免费开放**：全文开放、示例免费运行，无任何访问门槛。

## 🚀 本地运行

### 方式一：直接跑 Go（需要已构建前端 `web/dist`）

```bash
# 构建前端
cd web && npm install && npm run build && cd ..

# 启动服务（默认 :8080，exec 沙箱）
go run ./cmd/server -addr :8080
```

### 方式二：Docker Compose（推荐，一键起全套）

```bash
docker compose up -d --build
```

之后浏览器打开 **http://localhost:8080**。

> 运行镜像保留了 Go toolchain，用于进程内沙箱编译用户提交的示例；非 root 运行，工作区位于 `/workspace`。

## 📖 把它改造成另一本书（模板化）

本项目是一个**内容驱动的书籍骨架**：书的所有"差异内容"都放在 `content/` 与 `examples/` 两个目录，**前端与后端代码无需改动**，替换这两处即可变成别的书。

### 1. 书名与篇名 → `content/book.json`

```json
{
  "title_zh": "你的书名",
  "title_en": "Your Book Title",
  "subtitle_zh": "在线交互书",
  "subtitle_en": "Interactive Book",
  "parts": {
    "-1": { "zh": "前言", "en": "Preface" },
    "0": { "zh": "第一篇名", "en": "Part 1" }
  }
}
```

- 前端侧栏标题、浏览器标签页标题都会跟随它切换中英文。
- `parts` 以篇号（`part`）为键，可自由增删。

### 2. 每章正文 → `content/part-N/NN-slug/chapter.md`

每个目录一章，目录名形如 `part-0/01-intro/`。正文为 Markdown + 简单 front matter：

```markdown
---
id: part-0-01        # 全局唯一 id（也是分组的 key）
title: 章节标题        # 中文标题
title_en: Chapter Title  # 英文标题（可选，缺省回退中文）
part: 0             # 属于哪一篇（对应 book.json 的 parts 键）
sort: 1             # 篇内排序
example: 01-intro   # 可选：关联 examples 下的示例源码
---

# 正文（Markdown）
```

- 同一目录可提供英文版 `chapter.en.md`，供浏览器切换英文时展示。

### 3. 可运行示例 → `examples/NN-slug/main.go`

任意 `example:` 字段引用的示例源码，存放到 `examples/<id>/main.go`。前端章节页会自动展示编辑器并支持在沙箱中运行；不需要示例的章节省略 `example` 字段即可。

### 4. 重新构建

```bash
cd web && npm run build      # 重新打包前端（若改了前端）
go build ./...               # 把新 content/examples 打进二进制
```

之后运行单二进制即可，页面自动呈现你的新书内容。

## 🛡️ 沙箱与安全

- **MVP（exec）**：用户代码写入临时 `main.go` → `go build` → 限时运行，捕获 stdout/stderr；有超时、内存、输出截断与 IP 限流。
- **生产（docker）**：非 root、只读根文件系统、禁用网络、限额（memory/cpu/pids）、收缩 capabilities + seccomp；编译/运行容器分工，可预启热容器池复用。
