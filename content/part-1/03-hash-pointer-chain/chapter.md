# 哈希即指针：数据块如何被"链"起来

有了"雪花球"一样的哈希能力，区块链得到它名字里最关键的那个字——**链**。

## 想法：用哈希当"钩子"

每个区块不只存自己的数据，还额外存了**上一个区块的哈希指纹**。这个"上一个的哈希"就像一根钩子，把本块牢牢挂在前面那块上，所以叫**哈希指针（hash pointer）**。

```
[创世块] hash=A ─┬─► 下一个
[块1] data + prev=A ─ hash=B ─┬─►
[块2] data + prev=B ─ hash=C
```

由于哈希有**雪崩效应**和**单向性**：
- 前面任何一块的数据被改动，它的哈希就变；
- 后面所有块里存的"prev"都会对不上号 → **整条链当场断给你看**。

## 为什么"只记一个哈希"就够了？

不需要给每个区块单独设防，只要**保住链上最后一个哈希**，就能反推出整条链有没有被篡改。这极大降低了"校验成本"——正如现实中，你只需要牢牢记住账本的"最后一页"。
