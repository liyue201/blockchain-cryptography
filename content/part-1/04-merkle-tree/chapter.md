# Merkle 树：把一堆哈希汇总成一个根

一条链上可以装下**成千上万笔交易**。可如果"校验整条链"要逐个比对每笔交易，代价就太大了。Merkle 树就是回答这个问题的大杀器：**把一堆交易压缩成一个"根"，且任何一个交易变了，根也会变。**

## 怎么"垒"起来的？

把每笔交易先各自哈希，得到一串**叶子**；然后**两两配对再哈希**，逐层向上，直到剩下一个——叫 **Merkle 根**。

```
        根 = H( 中间层0  +  中间层1 )
              /                    \
   中间层0=H(L0,L1)          中间层1=H(L2,L3)
      /        \              /        \
   L0=H(Tx_A) L1=H(Tx_B)  L2=H(Tx_C) L3=H(Tx_D)
```

## 这个"树"带来两个惊人好处

1. **一个根，盖全账本**：头区块里只需要记一个 `merkle_root`，就能代表整块里的所有交易。
2. **一改就露馅**：任何一笔交易变了，会沿着它所在的路径一路传染到根，根一变全网都察觉。

Merkle 树的美好还远不止于此——下一节我们讲，轻钱包怎么**只下载一条路径**，就能证明"我的那个交易确实在块里"，而不必下载整块数据。
