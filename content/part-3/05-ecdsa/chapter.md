# ECDSA：链上最主流的签名算法

比特币、以太坊的交易签名用的都是 **ECDSA（椭圆曲线数字签名算法）**。它把"私钥盖章、公钥验章"落实在 secp256k1 这条曲线上。

## 一次性读懂签名公式

设消息哈希为 `z`，私钥 `d`，随机数 `k`，基点 `G`：

```
r = (k·G).x  mod n
s = k⁻¹·(z + r·d)  mod n
签名 = (r, s)
```

验签时只需公钥 `Q=d·G`：

```
u₁ = z·s⁻¹,  u₂ = r·s⁻¹
(u₁·G + u₂·Q).x  mod n  是否等于 r ？
```

**为什么成立？** `u₁·G + u₂·Q = (z·s⁻¹ + r·s⁻¹·d)·G = s⁻¹(z + r·d)·G = k·G`，恰好回到 x 坐标 r。这条代数等式正是"签名可验证"的全部秘密。

## 那个无处不在的"随机数 k"

功能多，风险也大——**k 绝不能泄漏或复用**！因为一旦 k 泄漏，立刻能解出私钥 `d = (k·s - z)·r⁻¹`；历史上一度有多起"随机数复用"导致巨额私钥被算出的安全事故。

## 解法：RFC6979 确定性签名

用私钥和消息哈希**推导出唯一的 k**（而不靠系统随机数），签名立刻变"确定"：

- 同一签名者 + 同一消息 = **永远同一签名**，杜绝 k 复用；
- 更稳、可复现、利于审计。
