# Ed25519：更现代、更快、更不怕侧信道

除了 ECDSA + secp256k1，现代系统越来越多地采用 **Ed25519**。它并非"另一条曲线"那么简单，而是整套设计理念的升级。

## 一句话记住它

> Ed25519 把 ECDSA 时代最容易翻车的三件事——随机数复用、侧信道泄漏、签名体积——一次性都处理掉了。

| | ECDSA + secp256k1 | Ed25519 |
|---|---|---|
| 随机数 k | 靠系统随机数（复用会泄漏私钥） | 由（私钥+消息）**确定派生**，无需随机源 |
| 侧信道 | 对实现要求高 | 恒定时间，天然抗计时攻击 |
| 签名长度 | 64~72 字节 | 固定 64 字节 |
| 验证速度 | 快 | 更快、实现更简单 |

## 关键：让"随机数"消失

Ed25519（EdDSA 的一种）把签名所需的那份随机分量**变成确定性的函数**，于是：

- 不再依赖随机数生成器的质量；
- 不存在"复用 k → 私钥泄漏"这扇后门；
- 同一消息永远签出同一签名，便于缓存与审计。

## 为什么要了解它

- 它对**新手友好、实现极难写错**；
- 链上虽然仍以 secp256k1/ECDSA 为主，但冷钱包、互操作协议里 Ed25519 的身影越来越多；
- 未来新链更倾向它，属于"链条密码学"里值得提前认识的名字。
