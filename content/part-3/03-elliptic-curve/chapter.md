# 椭圆曲线 ECC 入门：一条充满"单向秘密"的曲线

第 1、2 节我们用 RSA 建立方向感。而**区块链真正使用的其实是椭圆曲线（ECC）**。本节先抛开细节，只抓最核心的直觉。

## 一条曲线和一个群运算

椭圆曲线是满足 `y² = x³ + a·x + b` 的一串点。关键是：**两个点可以"相加"，一个点可以"自己加自己"**，这形成了封闭的"群运算"。

而真正重要的运算是**标量乘法**：

```
k·G  = G + G + ... + G   （k 次点加）
```

## 单向性：ECC 的安全根基

如同 RSA，ECC 也建立在一个不对称的能力上：

- **正向（容易）**：已知代数 k 和基点 G，算出 `k·G` 只需一次标量乘，CPU 眨眼完成；
- **反向（极难）**：已知 `k·G`，反推 k 要解"椭圆曲线离散对数问题"，目前无多项式算法，2^256 空间不可穷举。

**这正是私钥/公钥的由来：**
```
私钥 k ──点乘──► 公钥 Q = k·G
Q 反推 k    「做不到」
```

## 为什么比 RSA 香

同样安全强度，ECC 的密钥短得多（256 位 ≈ RSA 3072 位以上），签名更小、验证更快——**链上每笔交易的签名都要全世界每个节点重复验证**，这个账算下来 ECC 完胜。

> 运行右侧代码，看一个随机私钥 k 变成公钥 k·G，并留意 `2·G` 也是完全不同的一点。真正理解：正向秒出，反向永远拿不到。
> 我不是在培养你把曲线画漂亮，而是记住那行总结——**「从 k 到 k·G 快，反着来无路可走」**。
