# 后量子密码：给十年后的资产上保险

今天你私钥的 ECDSA 大量依赖**大整数分解 / 离散对数**这两个难题。可一旦出现可用的量子计算机，**Shor 算法**能指数级加速这两个难题——今天"安全"的签名会瞬间归零。所以业界提前研究**后量子密码**，趁现在给十年后上保险。

## 两种路线

1. **基于哈希的签名**：只用单向哈希。哈希没有高效的量子攻击（Grover 只能把搜索减半），于是天然抗量子。路线的代表就是 **LMOTS / XMSS / SPHINCS+**。

> 运行右侧代码——一个**完整可跑的 Lamport 一次性签名**。核心极其直观：

```
每个消息位(bit)：
  私钥：预留 2 个随机值  [bit=0 时用第0个, bit=1时用第1个]
  公钥：把每个私钥值哈希后公开
  签 名：按消息哈希的每一位, 挑出那一位对应的私钥值
  验 证：对每个签名值再哈希, 与公钥比对
```

> 你看，全程只有 `SHA-256`，没有分解也没有对数——这就是"后量子"的最小形态。原消息验签为 `true`，篡改后 `false`。

2. **格密码**：基于高维格上的困难问题（如 LWE/SIS）。比哈希型更小更快，也是 NIST 新标准（**ML-KEM / ML-DSA**，前身 Kyber / Dilithium）的主力路线。

## 现实处境

- **窃取后解密（harvest now, decrypt later）**：攻击者今天先把你的密文/公钥囤起来，等量子机成熟再批量破解——所以"早晚都要迁移"，早设计更稳妥；
- **迁移成本高**：密钥/签名体积、兼容性都变化巨大，业界在逐步铺路（对照第 4 篇讲的签名大小，LM 的一次性签名就有约 8KB）。

## 边界提示

本节用 Lamport 演示**"哈希型后量子"的第一性直觉**，并不是生产级方案（一次性、密钥巨大）。真正的工程化要配 Merkle 树做成可重用（XMSS/SPHINCS+），或用格密码（ML-DSA）。但它们想防御的靶子是一致的——**哪怕真的来了量子计算机，你的资产也还有数学可依仗。**
