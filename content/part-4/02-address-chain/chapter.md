# 从私钥到地址的完整推导链

有了私钥，就能推导出整个"身份"：**私钥 → 公钥 → 公钥哈希 → 校验 → 地址**。这是一条**单向**不可逆的链——向前走人人可以验证，向后倒退别人做不到。

## 五步走

1. **私钥 d**：256 位真随机数（上一节）。
2. **公钥 Q = d·G**：椭圆曲线标量乘法（第 3 篇 05 学过），得到曲线上的点。压缩成 33 字节（`02/03` + x 坐标）。
3. **公钥哈希**：对公钥做哈希（真实用 RIPEMD160，本教程用双重 SHA-256 近似），得到 20 字节的"指纹"。
4. **加版本与校验**：前缀 `0x00` 表示主网地址；再把"前缀+哈希"整体做哈希，取其前 4 字节作为校验和，拼到末尾。**校验**用于把"手打错一个字符"的地址在链上拒绝掉。
5. **Base58Check 编码**：Base58 是"去易混淆字符"的字母表（去掉了 0/O、1/l、I 等），比十六进制更适合人眼抄写。

> 运行右侧代码，能看到每一步的中间产物（私钥→公钥→哈希→校验→最终地址 `17uf...`）。它把第 1、3、4 篇讲过的**哈希、标量乘法、编码**全部串成一条实务链条——这就是比特币/众多链上"地址"的真实诞生过程。

## 为什么是不可逆的

全程只用了**单向函数**：标量乘法的离散对数难以反解，哈希必不可逆。于是任何人都可以通过你的地址验证你的公钥与身份，但没人能从地址倒推出私钥——**身份公开，权力私有**。

## 小知识

- 校验错误 = 打错字几乎必被拒，避免把资金打进废地址。
- 地址并不是"账户余额表"——余额属于*(公钥对应的私钥)*，由链上记账站在内部维护。
