# 用签名"花掉"一个地址：交易授权

最后一块拼图：私钥到底怎么"把币花出去"？——**不是把交易加密，而是给交易签章**。理解这一点，就理解了区块链公开账本为什么安全。

## 一笔交易长什么样

最简单的转账交易就是几段明文：

```
from  = 我的地址
to    = 收款地址
value = 金额
nonce = 账户编号（防重放，见第 3 篇 07）
```

**交易内容完全公开可读**——这不是缺点，反而是特性：区块链本就是"放给所有人看的账本"。

## 签名做了什么

- **哈希**：先把交易内容哈希成摘要（transaction hash）；
- **签名**：用发送方**私钥**对摘要做 ECDSA 数学盖章，得到 `(r, s)`；
- **授权语义**：签名 = "我，私钥持有人，明确同意这笔变动"；
- 任何人（矿工）用你的**公钥**当即可验签，确认这枚章是你盖的。

> 运行右侧代码，亲手看三种情况：合法交易验签 `true`；**偷偷改金额**、**回滚 nonce 重放**，验签都变成 `false`。内容里任何一个字节变动，旧章就失效——这就是「防篡改 + 防重放」来自数学，而非信任。

## 为什么是"授权"不是"加密"

🔐 加密 = 把内容**藏起来**（别人读不到）。

✍️ 签名 = 把内容和**作者**绑定（人人都能读，但只有你能写）。

区块链要的是**后者**：

- 账本对所有人公开（若加密就没人能对账）；
- 但只有私钥持有人能"盖章"通过某笔转账；
- 于是"公开透明 + 不可伪造"同时成立。

