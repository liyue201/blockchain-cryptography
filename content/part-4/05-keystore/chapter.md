# 私钥的保管：KDF、冷热存储与策略

私钥就是资产；那么"怎么放"就决定了资金的风险。这一节讲两层：**加密存放**（技术层）与**冷热分离**（策略层）。

## 不只存，还要加密存：KDF

直接把私钥裸存在磁盘/云盘，一旦泄露就完了。专业钱包会先用**口令 + KDF**把私钥加密成密文再落盘：

- **盐（salt）**：每次随机，保证同一口令也得到不同密文；
- **KDF（如 PBKDF2/scrypt/Argon2）**：把"口令 + 盐"做**大量重复哈希**得到密钥，让口令猜测极慢；
- 用这个密钥做 **AES-GCM** 加密私钥——GCM 自带**认证**，一旦口令错误会"明文拒绝"，绝不会返回一堆篡改过的假私钥。

> 运行右侧代码：强口令加密钱包文件 → 正确口令原样解锁、**错误口令被 GCM 认证拦截**。KDF 的意义就在于：口令通常是人类记忆的、很弱；慢哈希把每次爆破"拖慢到秒级"，百万次尝试就是几十天——把"好不好猜"的差距抹平。

## 冷热分离策略

- **热存储**：连着网络的设备（手机、交易所）持有——方便但暴露面大；
- **冷存储**：完全离线的设备 / 纸片 / 硬件钱包——从不联网，私钥最安全；
- 实践中：**用强口令把钱包加密**，然后"私钥"永远只在离线机器上存在，线上只放密文。即使服务器被拖库、硬盘被偷，拿不到口令就解不开私钥。

## 保管清单（这本书的安全底线）

1. 助记词 / 私钥**绝不**拍照、截图、存云盘、明文微信发送；
2. 用强口令 + KDF 加密；口令不要是常见词（去上节的"随机性"思路）；
3. 大额资金走**冷存储**，小额度用热钱包；
4. 定期轮换 / 复核备份，多份异地存放；
5. 记住：**只有掌握私钥，才算真正拥有资产**——交易所能冻结你的余额，自托管才彻底。
